Ajuda & Atalhos de Teclado

TextTools é uma coleção completa de ferramentas offline gratuitas de processamento e manipulação de strings. Todos os algoritmos rodam de forma privada e segura no seu próprio navegador.

Atalhos Rápidos de Teclado

Use estas combinações globais para disparar as manipulações mais frequentes instantaneamente:

Atalho Operação
Ctrl + Shift + U Converter texto selecionado/completo para UPPERCASE
Ctrl + Shift + L Converter texto selecionado/completo para lowercase
Ctrl + Shift + C Capitalizar Palavras (Primeira letra de cada palavra maiúscula)
